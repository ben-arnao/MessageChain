Backup

Your private key never leaves this machine. The keyfile you passed to messagechain ui --keyfile IS your backup — copy it to a second secure location (paper, steel, USB, another machine) and treat it like a password. There is no "recover wallet" path on the chain (per CLAUDE.md): lost key = lost wallet, by design.

Key rotation

WOTS+ leaves are one-time signatures. When the sigs remaining count above gets low, run messagechain rotate-key on the CLI — the new-tree keygen takes minutes and is not yet wired to the wallet UI (would block the HTTP request past every reasonable browser timeout).
